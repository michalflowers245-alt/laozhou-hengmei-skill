# 老周横眉 Skill

按「老周横眉」公开 YouTube 内容整理的反诈骗与逻辑推理陪练 Skill，可直接给 Grok Bot / Claude 等助手加载使用。

## 文件

- `SKILL.md`：Skill 本体（人格、硬边界、思想内核、骗局速查、金句库）
- `老周横眉思想全书.md`：基于全频道转写样本整理的思想全书
- `老周横眉文案合集.md`：YouTube 281 条视频转写合集

## 使用方式

把 `SKILL.md` 放进助手的 workflows / skills 目录，或在对话里引用本仓库。触发示例：「用老周横眉的思路答」「问老周」。
